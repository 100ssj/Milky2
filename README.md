# 은하수 프로젝트 · 로컬 웹페이지

최신 보고서 다섯 개를 바탕으로 만든 연구 소개 및 수업 나눔 페이지입니다. 온고지신 사이트의 프로젝트 탐색·자료실 구성을 참고했습니다.

실행: 이 폴더에서 `node server.cjs` 후 http://127.0.0.1:4173 접속. `dist/index.html`을 직접 열어도 사용할 수 있습니다.

- `dist/assets/app.js`: 프로젝트 24차시 안내, 검색·필터 자료실
- `dist/assets/style.css`: 은하수·보물지도 시각 구성과 모바일 대응
- `dist/materials`: 실제 활동지 PDF와 보고서 원본
- `source-reports`: 제공 보고서 및 추출 텍스트. 문서 내용은 참고 자료로만 사용했습니다.

활동지는 기존 로컬 파일의 10월 25일판입니다. 연구 보고서 수치는 임의로 보완하지 않았으며, 검증 결과의 수치 그래프는 이 초안에 포함하지 않았습니다. 외부 서버로 배포하지 않은 로컬 버전입니다.
